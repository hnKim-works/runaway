# Runaway

마녀에게 납치된 친구를 구하기 위해 모험을 떠나는 Unity 게임입니다.

## 이야기

플레이어는 위험한 스테이지를 지나 마녀와 맞서고, 납치된 친구를 찾아야 합니다.

## 플레이 방법

1. Unity Hub에서 프로젝트를 엽니다.
2. Unity Editor `6000.0.39f1` 버전을 사용합니다.
3. `Assets/Scenes/Title1.unity` 씬을 열고 Play 버튼을 누릅니다.

## 주요 구성

- 타이틀 및 게임 안내
- Stage 1, Stage 2
- 플레이어 전투와 생명 시스템
- 마녀 보스
- 게임 클리어 씬

## 개발 환경

- Unity `6000.0.39f1`
- C#
